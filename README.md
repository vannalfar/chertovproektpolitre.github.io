# «Хождение за три моря» — интерактивная карта

## Запуск
Откройте `index.html` в современном браузере. Политическая карта, границы и линии маршрута встроены в HTML; интернет для самой схемы не требуется.

## Управление
- Перетаскивайте карту мышью, удерживая левую кнопку.
- Используйте колёсико мыши или кнопки `+` / `−` для масштабирования.
- Нажимайте на точки или выбирайте город в левой панели, чтобы открыть справку и фрагмент произведения.
- Используйте переключатели «Весь путь», «Путь туда» и «Возвращение».
- Кнопка с домиком возвращает исходный вид карты.

## География
Контуры современных государств основаны на данных Natural Earth. Подписи стран расположены по географическим координатам внутри соответствующих территорий; для небольших стран применён уменьшенный размер шрифта. Подписи Средиземного, Чёрного и Каспийского морей, Персидского залива, Аравийского и Красного морей размещены в соответствующих водоёмах; для узких акваторий используются меньший шрифт и поворот подписи. Координаты городов показывают их современное местоположение, а исторический маршрут является реконструкцией.
